Oracle → PostgreSQL

Keep the application.
Change the database.

Orafit is a bounded SQL/JDBC compatibility layer that helps Oracle-oriented Java applications run on PostgreSQL with fewer application changes.

アプリはそのまま。
DBをPostgreSQLへ。

Orafitは、Oracle向けJavaアプリケーションを少ない変更でPostgreSQLへ移行するための、範囲を限定したSQL/JDBC互換レイヤーです。

Designed for migration移行のための設計

Compatibility where it matters.
Rejection where it doesn’t.

Orafit translates supported Oracle SQL at the JDBC boundary and supplies the server-side semantics PostgreSQL does not provide. Unsupported behavior is rejected instead of guessed.

必要な互換性は保つ。
曖昧な動作は推測しない。

対応済みOracle SQLはJDBC境界で変換し、PostgreSQLに不足する意味論はDB側で補います。安全に再現できない挙動は近似せず拒否します。

01

Translate at JDBC

Keep Oracle-oriented SQL close to the application while Orafit rewrites only the supported structures.

JDBCで変換

Oracle向けSQLをアプリ側に残しつつ、対応している構文だけをOrafitが変換します。

02

Add missing semantics

orafit provides the database-side behavior needed by translated SQL, without patching PostgreSQL itself.

DB側の意味論を補完

orafitが必要なDB側挙動を提供します。PostgreSQL本体へのパッチは不要です。

03

Fail closed

If Oracle-visible behavior cannot be preserved safely, Orafit rejects it instead of silently changing the result.

Fail closed

Oracleから見える挙動を安全に保てない場合、結果を黙って変えるのではなく明示的に拒否します。

Quick Startクイックスタート

Use a familiar JDBC connection.

Add Orafit and pgJDBC to the application classpath, then switch to the Orafit JDBC URL. Build and test use one Maven entry point.

いつものJDBC接続から始める。

OrafitとpgJDBCをapplication classpathへ追加し、JDBC URLをOrafitへ切り替えます。ビルドとテストの入口はMavenだけです。

Evidence over assumptions推測ではなく証拠

Oracle compatibility is executable.

Support claims come from canonical Oracle-visible cases and differential tests, not from PostgreSQL behavior alone. The compatibility matrix is the public contract.

Oracle互換性を実行可能にする。

サポート範囲はPostgreSQL側の結果だけでは決めません。Oracle-visibleなcanonical caseと差分テストを根拠にし、互換性マトリックスを公開契約とします。

Bounded by design意図的に範囲を限定

Not an Oracle emulator.

Orafit targets migration-critical SQL/JDBC behavior. It does not try to reproduce every Oracle subsystem or undocumented edge case.

Oracleエミュレーターではありません。

Orafitは移行で重要なSQL/JDBC互換性に集中します。Oracleの全サブシステムや未文書化の挙動を再現することは目的にしません。
